# Décisions d'architecture

Ce dossier contient uniquement les décisions durables ayant un impact sur l'architecture, la sécurité ou les conventions du projet.

Chaque fichier suit le format :

```markdown
# NNN — Titre

Date: YYYY-MM-DD
Statut: proposée | acceptée | remplacée

## Contexte

Pourquoi une décision est nécessaire.

## Décision

Choix retenu.

## Conséquences

Effets positifs, compromis et risques.
```

Ne pas utiliser ces fichiers comme journal d'avancement. Si une décision est remplacée, conserver le fichier et pointer vers la nouvelle décision.
